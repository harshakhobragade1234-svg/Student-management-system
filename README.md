# Student Management System
Full Stack Project by Harsha Khobragade

## Features
- Add Student
- View Students
- Search Student
- Delete Student
- MySQL Database

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Java (JSP, Servlet)
- Database: MySQL

## How to Run
1. Create database studentdb
2. Run the sql file
3. Deploy on Tomcat
